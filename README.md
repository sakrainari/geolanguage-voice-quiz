# GeoLanguage Voice Quiz

県名・行政地域名を優先して、日本語の声で外国の地名を読むゲーム。

元の [GeoLanguage Quiz](https://github.com/sakrainari/geolanguage-quiz) とは独立した、ビルド不要の静的Webアプリです。

公開サイト: **https://sakrainari.github.io/geolanguage-voice-quiz/**

Chromeで開き、「文字体系 → 国 → 練習内容」を選んで始めてください。音声認識にはマイクの許可が必要です。[使い方](https://sakrainari.github.io/geolanguage-voice-quiz/manual.html)

ウクライナは24州・クリミア自治共和国・特別な地位の2市、モンゴルは21県と首都、ブルガリアは28州、キルギスは7州と直轄2市、カザフスタンは17州と直轄3市を地域モードに収録しています。都市モードは各12件の学習用選集で、キルギスはジャラルアバドの旧称と現在名マナスを含みます。

## 主な機能

- 県・行政地域／代表都市／地域優先ミックス、5・10・20・全問。
- 日本語音声認識。四択・文字入力回答はありません。
- 出題の原語から県・州・市などの行政区分を省略。`제주특별자치도` は `제주` と表示し、「チェジュ」で回答できます。元の表記は解説に表示します。
- かな・全半角・区切りを正規化し、長音「ー」を除去。ヴァ・ヴィ・ヴ・ヴェ・ヴォをバ・ビ・ブ・ベ・ボへ、小書きのャュョァィゥェォを大きい文字へ統一。回答と登録された読みの両方に適用します。
- 報告された聞き取り違いは問題ごとに補正。「ランプ」→「ランプーン」はランプーンの問題にだけ適用し、聞き取った言葉と補正内容を表示します。
- 確定音声の候補を最大5件要求し、いずれかの候補が正規化後の登録回答と完全一致すれば正解。途中結果は採点しません。
- 「あのー」「あの」「うーん」「えー」「んー」などの前置きと、「だと思う」「かな」などの末尾を除去。
- 聞き取った候補、抽出した回答、判定理由を表示。第2候補以降で一致した場合も分かります。再録音可能。
- 自動の一発正解、再挑戦正解、自己申告を分けて記録。
- 間違えた問題をブラウザー内に保存し、選んだ言語・モードで復習。
- 設定画面から任意で開く独立したマイク確認ステージ。入力許可・機器名・音量バー・日本語の認識結果を確認できます。本戦の開始時には挟みません。
- マイクは明示操作でのみ開始し、離脱・答え表示・認識開始から15秒経過で停止。許可待ち時間は15秒に含めません。

## 起動

Node.js 20以降を想定。外部npmパッケージのインストールは不要です。

```sh
npm start
```

表示された `http://127.0.0.1:4178` をChromeで開いてください。音声認識にはネット接続とマイクの許可が必要です。公開するときはHTTPSを使ってください。

## 検証

```sh
npm test
```

39件の自動テストで、495問の全回答・別名、出題表記の省略、短い地名の回答、全候補の判定、正規化、前置き・末尾の除去、問題を限定した認識補正と誤答拒否、国別の出題・復習・保存耐性、確定結果のみの処理、古い録音イベント、認識開始からの録音上限、マイク確認時の入力取得・キャンセル・解放を検証します。実アプリの独立したマイク確認、国選択・採点・成績・復習・地図リンク、チェジュの短い出題と第2候補による正解、ランプーンの補正表示も、模擬DOMと模擬音声サービスで確認します。実画面の見た目と実マイクの聞き取り精度は別途確認が必要です。

## GitHub Pages

`.github/workflows/pages.yml` はmainへのpush時にテストし、公開用ファイルだけをPagesへ配置します。GitHubの Settings → Pages → Source で GitHub Actions を選んで使います。

公開用リポジトリは `sakrainari/geolanguage-voice-quiz`、PagesのSourceはGitHub Actionsです。デプロイの状態は [Actions](https://github.com/sakrainari/geolanguage-voice-quiz/actions) で確認できます。

## ファイル

- `index.html`, `style.css`, `app.js`: 画面・ゲームの状態と成績
- `data.js`: 問題と個別の別名
- `data-cyrillic.js`: 追加5か国の地域・都市名と別名
- `catalog.js`: 文字体系・国・表示言語・地図の対応
- `core.js`: 判定・出題・復習保存
- `speech.js`: 音声認識のセッション管理
- `mic-check.js`: 独立したマイク確認の入力計測・日本語認識・リソース解放
- `spec.html`: 実装前にまとめた仕様
- `manual.html`: 完成後にまとめた操作マニュアル

音声や認識全文はアプリで保存しません。ブラウザー提供元の認識サービスに音声が送られる場合があります。
